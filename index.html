Signal Generation

Five Strategies, One Pool

All five strategies generate signals independently. The Strategy Agent regime-weights them, then the LLM filter selects only the highest-conviction setups across all strategies.

📊

Trend Following

EMA 20/50 crossover with RSI confirmation filter. Rides directional momentum in bull and bear regimes. Weight amplified to 1.5× in trending markets.

🚀

Momentum Breakout

Donchian 20-period channel breakout requiring 1.5× average volume confirmation. Captures explosive moves at the start of new trends.

🔄

Mean Reversion

Bollinger Band touch with RSI extreme confirmation. Fades overextended moves in ranging markets. Weight 1.5× in sideways regimes.

⚡

Volatility Arb

Exploits funding rate extremes on perpetual futures. Extreme positive funding → fade longs. Negative funding → fade shorts. Contrarian by nature.

🔃

Portfolio Rotation

Ranks all trading pairs by risk-adjusted momentum (ATR-normalized). Rotates capital into the top 2 performers each cycle.

🧠

Regime Adaptation

Strategy weights shift dynamically. Bull trend amplifies momentum; ranging markets amplify mean reversion; high volatility amplifies vol arb by 1.8×.

Philosophy

Elite Trader Principles

Rules encoded into the system, not aspirations on paper. Every trade must satisfy all constraints or it does not execute.

🔐

Capital First

15% portfolio drawdown triggers a Redis-persistent kill switch. All trading halts. Manual operator reset required. State survives restarts.

🎯

High Conviction Only

GPT-4o filters raw signals. Minimum 55% confidence score. Minimum 1.5:1 risk-reward. Signals below threshold are discarded, not traded.

📏

Precise Sizing

Kelly criterion adjusted by signal confidence. 0.25–0.5% equity at risk per trade. Hard cap at 20% of equity per position.

📈

Compound Winners

80% of realized profits are reinvested each cycle via the compounding engine. 20% reserved as buffer. Allocation proportional to strategy weights.

🌊

Regime Awareness

Seven market regimes detected per cycle. Strategy weights dynamically adjust. No strategy runs at full weight in an adverse regime.

📋

Full Auditability

Every order — filled or failed — writes to an immutable TimescaleDB audit log. Every cycle is embedded in Qdrant for post-mortem analysis.

Enterprise Security

25 Vulnerabilities Fixed

A full enterprise security audit was completed against OWASP Top 10 and financial-system threat models. Every finding was resolved before production.

FIXED
API Authentication (A07) X-API-Key bearer token required on all /api/v1/* endpoints and WebSocket. No unauthenticated access to any data or operation.
FIXED
Persistent Kill Switch Redis-backed kill switch survives restarts and is shared across all workers. Cannot be bypassed by redeployment.
FIXED
Race Condition (A07) asyncio.Lock protects all reads and writes to shared cycle state. Concurrent requests cannot corrupt the signal pipeline.
FIXED
Prompt Injection (A04) All user-controlled and external values sanitized before LLM injection. Pydantic schemas validate every LLM response.
FIXED
Infrastructure Hardening Redis requirepass, Qdrant API key, all ports bound to 127.0.0.1. Credentials via env vars with required validation.
FIXED
Rate Limiting + DoS Protection 5-minute per-IP cooldown on cycle triggers. WebSocket capped at 50 connections and 4-hour session limit.

Deployment

Quick Start

Docker Compose runs the full stack locally in minutes. Paper trading is enabled by default — no real funds at risk.

# 1 — Clone and generate secrets $ git clone https://github.com/BigXero01/SFOMO.git && cd SFOMO $ cp .env.example .env $ python -c "import secrets; print(secrets.token_hex(32))" # → SECRET_KEY $ python -c "import secrets; print(secrets.token_hex(32))" # → API_KEY # 2 — Fill in .env (OPENAI_API_KEY, exchange credentials, secrets above) $ nano .env # 3 — Start full stack (Postgres, Redis, Qdrant, backend, frontend) $ make up # 4 — Watch logs $ make logs # 5 — Open dashboard and API docs $ open http://localhost:3000 # Dashboard $ open http://localhost:8000/docs # Swagger UI (dev only) # 6 — Trigger your first cycle $ curl -X POST http://localhost:8000/api/v1/signals/run-cycle \ -H "X-API-Key: YOUR_API_KEY" \ -H "Content-Type: application/json" \ -d '{"symbols":["BTC/USDT","ETH/USDT"],"timeframe":"1h"}'

Deploy: Frontend

Import BigXero01/SFOMO on Vercel, set root directory to frontend, add NEXT_PUBLIC_API_URL. Auto-deploys on every push.

Deploy: Backend

Import on Railway, set root to backend. Add PostgreSQL + Redis plugins — Railway injects connection strings automatically.

Vector DB

Create a free cluster on Qdrant Cloud, add the URL and API key to Railway environment variables.
